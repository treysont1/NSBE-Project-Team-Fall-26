# NSBE-Project-Team-Fall-26

## Overview

We will develop the softwawre that powers our RC car and build a mobile application that allows users to control the car from their phones.

## Project Goals
- Develop the software to control the RC car's movement and functionality

- Integrate the hardware and software to create a working system
